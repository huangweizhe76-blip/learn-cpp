# 队列 Queue 学习笔记
> C语言实现三种队列：普通顺序队列、循环顺序队列、链式队列。
> 环境：Visual Studio 2022 / GCC；标准C99。

## 队列基础概念
队列：**先进先出 FIFO**。
- 入队(enqueue)：在队尾增加元素
- 出队(dequeue)：从队头取出元素
- 队头：front；队尾：rear

### 三种实现对比
| 类型               | 文件         | 存储结构 | 判空条件        | 判满条件                            | 特点                                                         |
| ------------------ | ------------ | -------- | --------------- | ----------------------------------- | ------------------------------------------------------------ |
| 普通顺序队列       | seq_queue.c  | 动态数组 | `front == rear` | `rear >= MAXSIZE`，数组前移复用空间 | 数组满时需要整体搬迁数据，效率差                             |
| 循环顺序队列       | circ_queue.c | 动态数组 | `front == rear` | `(rear+1)%MAXSIZE == front`         | 牺牲1个位置区分空与满；不需要搬迁数据；最大有效容量 `MAXSIZE‑1` |
| 链式队列(带头结点) | link_queue.c | 链表结点 | `front == rear` | 无需判满                            | 没有固定容量；堆动态分配；删除最后元素要重置rear指针         |

> 注意：循环队列牺牲一个存储单元，用来区分队列空和队列满。

## 文件说明
1. **seq_queue.c**
普通顺序队列，当`rear`到达数组上界，如果前面有空闲空间，将数组整体向前移动释放头部空间；真正数组占满才是队列满。存在大量元素移动开销。

2. **circ_queue.c**
循环顺序队列，使用取模运算实现下标循环绕回。固定最大容量。

3. **link_queue.c**
**优化后的带头结点链式队列**
- 使用哨兵头结点；`front`永远指向头结点；`rear`指向最后有效结点。
- 边界重点：当删除链表**最后一个有效结点时，必须手动将rear赋值回head，否则rear成为野指针**。
- 完整内存管理：`destroyQueue()`释放全部结点，解决内存泄漏。
- 接口规范：查询类函数使用输出参数+int状态返回值，解决元素为0和空队列无法区分的问题。

## API接口统一约定
> 三个实现尽量保持接口风格一致：

| 函数                                       | 作用                   | 返回值说明                                 |
| ------------------------------------------ | ---------------------- | ------------------------------------------ |
| `Queue* initQueue()`                       | 初始化队列             | 返回队列指针；分配失败退出程序             |
| `int isEmpty(const Queue* Q)`              | 判断队列是否为空       | 1为空；0非空；参数const只读保护            |
| `int enqueue(Queue* Q,ElemType e)`         | 入队                   | 1成功；0失败（顺序队列才会失败，链式不会） |
| `int dequeue(Queue* Q,ElemType *e)`        | 出队，结果存入*e       | 1成功；0队列空失败                         |
| `int getFront(const Queue* Q,ElemType *e)` | 获取队头元素，不删除   | 1成功；0队列空失败                         |
| `void destroyQueue(Queue* Q)`              | 销毁队列，释放全部内存 | 无返回；防止内存泄漏                       |

> ❗重要：使用完毕**必须调用 destroyQueue**释放malloc申请内存。

## 坑点总结
### 1.普通顺序队列 seq_queue.c
- 出队只做front++，不会释放数组；数组满触发数据整体平移。
- 数组大小固定MAXSIZE。

### 2.循环队列 circ_queue.c
- 实际可用元素数量：`MAXSIZE - 1`。
- 所有下标更新必须做 `% MAXSIZE`。

### 3.链式队列 link_queue.c
1. 删除最后一个结点，`rear`要重置回头结点，否则野指针。
2. 不要用返回元素值区分空队列，如果队列允许存储数字0会产生歧义。
3. 每一个`malloc`对应一处`free`；一定要写销毁函数。
4. 头结点不存储业务数据，只做哨兵。
