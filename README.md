📁 Directory Structure / 目录结构
1. cpp_basics｜C/C++ 语法基础
Covers C core syntax, C++ object-oriented features (encapsulation, inheritance, polymorphism) and STL containers & algorithms.
包含 C 语言核心语法、C++ 面向对象三大特性、STL 常用容器与标准算法实战。
2. data_structure｜手写数据结构与经典算法
Pure manual implementation of full-range underlying structures and algorithms, including linear tables, trees, graphs, sorting, searching, KMP and other string algorithms.
纯手写实现全套底层数据结构与经典算法，涵盖线性结构、树形结构、图结构、排序查找、KMP 等字符串算法。
3. algorithm_practice｜算法刷题实战
Classified algorithm practice from Luogu, AtCoder and UVA. Each problem is equipped with complete code, complexity analysis, problem-solving ideas and bug summary.
汇总洛谷、AtCoder、UVA 分类刷题记录，每题配套完整源码、复杂度解析、解题思路及踩坑复盘。
4. easyx_demos｜图形化编程练习
Basic graphical programming and mini game demos based on the EasyX library for visual programming ability training.
基于 EasyX 图形库的基础绘图练习与小型游戏 Demo，锻炼可视化编程思维与交互开发能力。
5. docs｜配套文档资料
Personal coding specifications, development environment configuration documents and summary of common compilation errors & solutions.
收录个人编码规范、开发环境配置教程、高频编译报错汇总与解决方案。
