\# LeetCode 27 移除元素 

🔗题目链接：https://leetcode.cn/problems/remove-element/ 

## 核心信息 

- 解法：快慢双指针，原地修改数组

- 时间复杂度：$O(n)$ 

- 空间复杂度：$O(1)$ 

  

  ## 关键点 

  - 1. slow：有效元素待写入下标；fast：遍历指针 

    2. fast遍历全部元素；不等于val才赋值给nums[slow]，slow++ 

    3. 返回 slow，slow的值就是有效元素个数k

    4. 题目允许数组元素顺序打乱，后面残余数值不用管 

       ## 踩坑

       ❌禁止开辟新数组，要求原地操作

       ❌不要返回numsSize，返回slow

       ❌slow不能每次循环都++，只有遇到有效元素才自增 

       ## 边界测试用例 

       全部元素都要移除 nums=[2,2,2], val=2 → 返回0

       全部元素保留 nums=[1,2,3], val=99 → 返回3 

       要删除的元素出现在头部、尾部
